<h1>DocuTalk</h1>

<p>DocuTalk is an application that enables users to interact with PDF documents using a Large Language Model (LLM). By leveraging advanced natural language processing capabilities, DocuTalk allows users to ask questions and receive answers based on the content of their PDFs.</p>

<h2>Features</h2>
<ul>
    <li><strong>Interactive Document Querying:</strong> Engage in a conversational interface to extract information from PDF documents.</li>
    <li><strong>LLM Integration:</strong> Utilizes the Gemini API to process and understand document content.</li>
    <li><strong>User-Friendly Interface:</strong> Built with Streamlit to provide an intuitive and accessible user experience.</li>
</ul>

<h2>How It Works</h2>
<p>DocuTalk processes PDF documents by extracting their text content and utilizing the Gemini LLM to interpret and respond to user queries. The application workflow involves:</p>
<ol>
    <li><strong>Document Upload:</strong> Users upload PDF files to the application.</li>
    <li><strong>Text Extraction:</strong> The application extracts text from the uploaded PDFs.</li>
    <li><strong>Query Processing:</strong> Users input questions related to the document content.</li>
    <li><strong>Response Generation:</strong> The Gemini LLM processes the extracted text and user queries to generate relevant responses.</li>
</ol>

<h2>Technologies Used</h2>
<ul>
    <li><strong>Python:</strong> The core programming language used for application development.</li>
    <li><strong>Streamlit:</strong> Provides the web-based interface for user interactions.</li>
    <li><strong>Gemini API:</strong> Powers the LLM functionalities for understanding and responding to queries.</li>
    <li><strong>PyMuPDF (fitz):</strong> Used for extracting text from PDF documents.</li>
    <li><strong>Python-dotenv:</strong> Manages environment variables, including API keys.</li>
</ul>

<h2>Installation and Setup</h2>

<p>To run DocuTalk locally, follow these steps:</p>

<h3>1. Clone the Repository:</h3>
<pre><code>git clone https://github.com/shreyansh-21/DocuTalk.git</code></pre>

<h3>2. Navigate to the Project Directory:</h3>
<pre><code>cd DocuTalk</code></pre>

<h3>3. Install Required Packages:</h3>
<pre><code>pip install -r requirements.txt</code></pre>

<h3>4. Configure the Environment Variable:</h3>
<p>Create a <code>.env</code> file in the project directory with the following content:</p>
<pre><code>GEMINI_API_KEY=your_gemini_api_key</code></pre>
<p>Replace <code>your_gemini_api_key</code> with your actual Gemini API key.</p>

<h3>5. Run the Application:</h3>
<pre><code>streamlit run app.py</code></pre>

<h3>6. Interact with Your PDFs:</h3>
<p>Open the provided local URL in your web browser to start interacting with your PDF documents.</p>

<h2>Usage</h2>
<ul>
    <li><strong>Uploading Documents:</strong> Use the file uploader in the application interface to upload your PDF files.</li>
    <li><strong>Asking Questions:</strong> Enter your questions in the text input field to inquire about the content of the uploaded documents.</li>
    <li><strong>Receiving Answers:</strong> View the responses generated by the application based on your queries.</li>
</ul>
